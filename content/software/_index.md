# We collaboratively maintain a number of open-source software packages for molecular modeling, simulation, and analysis.

1. MDTraj
2. PALE (protein alchemical landscapes explorer)
3. CARDS (and the CARDSReader package to interpret CARDS data)


# We actively collaborate with the following teams on open source software development

1. OpenFreeEnergy (Sukrit is a member of their technical advisory committee)
2. OpenFold (To develop better ways to seed/steer structure generation)
3. OpenMM (To develop better ways to run molecular simulations at scale)
4. Folding@home

## Sometimes the lab will also tinker with tools and repositories relevant to others

1. PicoViz
2. BindingSims
3. OffLeaf (an offline overleaf editor, for the LaTeX writer on the go - now with Text-to-speech!)
4. Sonya Hanson and my guide to massively parallel simulations (https://github.com/sukritsingh/massively-parallel-simulations)
